# Windows PC Demo 0.1

输出：`releases/AlgoTogetherDemo/AlgoTogetherDemo.exe` 与 `releases/AlgoTogetherDemo-0.1.0-win-x64.zip`。便携包需保留整个目录，EXE 不能单独分发。第一版原生 Java Swing 面板管理服务，业务页面在默认浏览器中显示。

## 构建

先构建 Maven 服务与前端。构建机器需要 JDK 21+ 的 javac/jar/jpackage、Node、MySQL 8.0、PowerShell 7 运行时与已下载的 cloudflared。运行 `desktop/build.ps1`，可指定 `-Jdk`、`-PowerShellRuntime`。构建脚本从 Adoptium 官方下载 Temurin 21 JRE，最终用户不需安装这些工具。生成目录已加入 Git 忽略规则。

已有 `desktop/build` 时脚本拒绝重建，避免覆盖验收数据；确认无需保留后再清理该构建目录。打包仅复制白名单 JAR、迁移脚本、已编译前端、启动脚本和第三方运行时，不复制项目 data、数据库、邮箱配置、API 密钥或身份私钥。

## 运行隔离

桌面版初始化 `%LOCALAPPDATA%/AlgoTogetherDemo/v1`，首次生成身份 RSA 密钥、群组密钥和数据库密码。MySQL 只监听 127.0.0.1:3317，采用独立业务账号和迁移账号。管理员邮箱由用户首次设置，密码在注册时自行设置。默认公网访问关闭。

桌面与开发版共享社区端口，因此先停止开发版再运行桌面版。桌面预检和停止脚本检查进程所属路径，不停止其他项目。关闭桌面面板时等待服务停止及数据库正常关闭；启动中禁用关闭操作。实例文件锁阻止同一个用户重复打开。

内置 MySQL 从用户工作目录启动，解决当前打包路径包含中文时 MySQL 自身解析可执行文件路径的问题；中文 Windows 用户名及其他系统版本尚未验收。

## 第一版验收记录

- 生成并启动实际 EXE，确认 Windows 桌面面板进程及标题。
- 使用包内 Temurin 21、PowerShell、Node、MySQL，未使用系统 Java 运行服务。首次初始化独立数据库 3317 成功。
- 从包内静态前端代理完成管理员注册登录。
- 验证普通用户申请公开及私密群组，审批前禁止部署，管理员审批后由申请人部署；禁止非申请人部署及重复部署。
- 两类群组代理、加入及讨论写入成功；私密群组错误密钥被拒绝，非申请人无法读取分发密钥，部署成功通知可读。
- 本机到局域网再到公网切换成功；局域网绑定 0.0.0.0 并展示地址。公网取得 Cloudflare HTTPS 地址，未开启管理员公网策略时外部请求为 403。
- 停止群组、身份、静态前端、网关、中继、隧道与独立数据库成功。验收账号与数据移入忽略的构建目录，未进入分发包。

尚未验收：其他电脑上的完整解压运行、真实远端成员联网、中文 Windows 用户名、生产长时间运行。本包未启用 RabbitMQ，站内消息采用现有数据库通知流程；模型及 OJ 配置由用户填写。
