# 群内交流与顾问场景审查

## 可重复执行验证

浏览器验收：在 frontend 目录执行 `npm run test:e2e`，使用本机 Chrome 无头测试，测试中会生成桌面及 390 像素窄屏截图。

先启动开发服务，随后运行 `pwsh -File scripts/test-communication-advisor.ps1`。脚本通过 Vue 开发代理访问真实身份服务和两个群组服务，并启动仅监听本机的模拟模型；结束时停止模拟模型。每次创建独立测试账号并留下明确标记的讨论，便于检查持久化数据。

## 审查判断

帖子加回复适合算法问答和复盘。后台逐次核验成员资格，讨论和回复同步事件原子落库。页面每 30 秒刷新讨论与已展开的回复，因此属于定时同步交流，不能称为即时聊天。成员撤销后服务端会拒绝新请求。

私人顾问会话按账号和群组隔离，不能自动广播给群友。模型调用前，用户需确认共享当前讨论和自己的最近会话；失败时不追加虚假的成功记录。模型生成后再核验成员权限。顾问目前是只读上下文咨询，不执行用户代码、不自动发布讨论。

模型请求期间用户修改输入时，回答必须匹配发出时的问题，保留用户后来输入的草稿。群组切换和退出登录清空可见上下文，旧请求结果通过群组版本校验丢弃。

## 并发与页面补充验收

AdvisorConcurrencyTest 已验证同一账号同一群组请求并发返回 409；清空历史通过数据库 generation 和行锁事务使正在生成的旧回答失效；模型超时、空回答不保存会话；失败后可以重新请求。该请求并发限制目前适用于单实例身份服务，多身份服务进程部署需增加共享锁。

浏览器端到端测试已实际操作注册、入组、普通用户创建入口、发布讨论、双用户回复、填写模型地址和密钥、两轮追问、刷新后加载历史、清空历史、群组切换和退出登录。桌面及窄屏截图已检查，修复确认框布局、折叠参考讨论，390 像素宽度没有横向溢出。

## 尚不能证明的项目

公网 NAT 穿透或中继尚未实现，本机双服务测试不能代替跨网络验收。浏览器控制工具故障已通过项目内 Playwright 测试替代，已取得实际点击与截图证据。用户已明确将在之后自行填入供应商配置，当前不测试真实模型回答质量。超时、重复请求、历史清空与生成竞争的自动化测试已通过。整体目标保持进行中。
