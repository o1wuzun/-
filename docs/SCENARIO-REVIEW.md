## 审查判断

帖子加回复适合算法问答和复盘。后台逐次核验成员资格，讨论和回复同步事件原子落库。页面每 30 秒刷新讨论与已展开的回复，因此属于定时同步交流，不能称为即时聊天。成员撤销后服务端会拒绝新请求。

私人顾问会话按账号和群组隔离，不能自动广播给群友。模型调用前，用户需确认共享当前讨论和自己的最近会话；失败时不追加虚假的成功记录。模型生成后再核验成员权限。顾问目前是只读上下文咨询，不执行用户代码、不自动发布讨论。

模型请求期间用户修改输入时，回答必须匹配发出时的问题，保留用户后来输入的草稿。群组切换和退出登录清空可见上下文，旧请求结果通过群组版本校验丢弃。

## 并发与页面补充验收

AdvisorConcurrencyTest 已验证同一账号同一群组请求并发返回 409；清空历史通过数据库 generation 和行锁事务使正在生成的旧回答失效；模型超时、空回答不保存会话；失败后可以重新请求。该请求并发限制目前适用于单实例身份服务，多身份服务进程部署需增加共享锁。

浏览器端到端测试已实际操作注册、入组、普通用户创建入口、发布讨论、双用户回复、填写模型地址和密钥、两轮追问、刷新后加载历史、清空历史、群组切换和退出登录。桌面及窄屏截图已检查，修复确认框布局、折叠参考讨论，390 像素宽度没有横向溢出。

## 尚不能证明的项目

反向 HTTP 中继与群组主机出站连接端已实现，test-relay.ps1 已验证讨论、回复、节点事件、跨组凭证隔离、撤销、离线与重连。本机测试不能代替跨网络验收；用户选择暂不部署公网，部署步骤见 REVERSE-TUNNEL.md。浏览器控制工具故障已通过项目内 Playwright 测试替代，已取得实际点击与截图证据。用户已明确将在之后自行填入供应商配置，当前不测试真实模型回答质量。超时、重复请求、历史清空与生成竞争的自动化测试已通过。当前群内交流与顾问原型已完成本机验收；真实供应商质量和跨公网部署另行验收。


## 本机主机公网入口补充验收（2026-10-11）

使用 Cloudflare 临时隧道和专用构建页面网关。真实公网 HTTPS 入口已验证页面、群组目录、注册登录、入组、双用户发布回复、未入组访问拒绝及私密文件不可访问；本机 Chrome 实际加载公网页面和两个群组卡片。当前网络 HTTP/2 连接失败，自动协议选择使用 QUIC 接通。地址发放不等于连接就绪，启动脚本检查 /ready 后才报告成功。测试来自主机经真实公网边缘，独立手机移动网络体验尚待人工验收。


## 公网邀请控制补充验收（2026-10-11）

PublicAccessTest 验证默认关闭、普通用户无管理权限、内部接口需要独立网关凭证、并发兑换只有一次成功、邀请摘要保存、撤销与到期、关闭后重开不恢复旧会话。网关测试验证页面/资源/API 无凭证拒绝、Secure/HttpOnly Cookie、跨来源兑换拒绝、验证服务故障拒绝放行及内部接口不发布。Chrome 经真实公网验证本机管理员生成邀请、外部浏览器兑换、完整页面加载、撤销后接口拒绝并回到访问页；结束后管理员开关保持关闭，测试邀请撤销。副本单测验证访问会话与节点凭证同时携带，拒绝时游标不推进。私有模式启动脚本已提供；独立数据部署与 PC 安装包仍待后续开发。


## MySQL 切换验收（2026-10-11）

中心身份与两个群组迁入本机独立 MySQL 8.0.41 实例，监听 127.0.0.1:3307。迁移前关闭服务并备份 H2，迁移后逐表核验计数与内容摘要。真实 MySQL 环境的双账号讨论回复、模型配置、私人会话、跨组与节点凭证隔离及 Chrome 操作通过。应用账号的 DDL 和跨服务库读取被拒绝；数据库正常重启前后，三个库的数据快照一致。H2 源文件保留，回退不包含后续 MySQL 新写入。

MySQL 下的真实公网管理员邀请／兑换／撤销 Chrome 验收通过。测试名称改为每轮唯一，避免保留下来的历史申请记录影响重复验收；结束后关闭公网权限并停止公网进程。
