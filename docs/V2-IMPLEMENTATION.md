# 第二版迭代验收清单

本清单保留完整需求；未验证项不能视为完成。第一版桌面打包与本迭代独立。

- [x] 群组范围与成员权限：计划、任务、草稿、提交、检查、复习、推荐及缓存互相隔离；个人记录只对本人开放。
- [x] 组长发布阶段计划、不可变版本、变更说明，成员加入并设置学习时间；任务快照不被新版本覆盖。
- [x] 领取任务，延期、换题、申请跳过及原因历史；延期完成与按时完成单独统计。
- [x] 草稿自动保存、正式提交、题目与总结及独立验证证据；切换群组不丢草稿。
- [x] 检查点补交、变式复测及历次结果；AI 异步检查、不可用重试、申诉。
- [x] 私人错题复习队列，主动选择公开分享，复习历史。
- [x] 周复盘、卡点与延期原因汇总、下一阶段计划确认。
- [x] 从任务求助，关联讨论，解决后理解回填。
- [x] 群组顶部切换器与阶段；概览、学习、交流、资料、成员五入口；Agent 固定辅助入口。
- [x] 学习页依次展示今日待办、需要处理、阶段进度、历史；推荐附原因。
- [x] 任务详情主栏及辅助栏（状态、期限、证据、资料、默认收起 Agent）。
- [x] 统一文字状态，耗时操作可离开再查看，重复提交防护。
- [x] 汇总只展示各组状态；显式跨组复制计划后独立管理。
- [x] H2 与 MySQL 迁移、权限/状态转换/并发测试、实际浏览器验收、部署文档。

用户资料及未提交的文档研究脚本不属于本迭代改动。


## 2026-10-17 验收证据

运行版本：Spring Boot + Vue 3 源码第二版；本机 MySQL 3307，社区 5173。第一版 EXE 未更新。

| 验收范围 | 对应实现与已执行的验证 |
| --- | --- |
| 群组与个人边界 | `StudyWorkflowController` 服务端群组范围及本人查询；`StudyWorkflowTest` 在同一个 H2 数据库模拟 A/B，拒绝跨组、跨用户与被撤销成员。`groupRequest` 捕获群组和登录身份，草稿缓存以用户/群组/任务分隔；浏览器验证 A/B 草稿与任务独立。 |
| Agent 与推荐隔离 | `AdvisorController` 仅查询当前组讨论、资料、本人学习记录及本组会话；`GroupLearningPlannerTest` 验证本组两版历史、排除全局记录、调用前后复查成员权限。`StudyJobsTest` 验证本组任务上下文、剔除两类草稿，不持久化令牌或模型密钥。 |
| 计划与版本 | `StudyWorkflowTest` 验证组长权限、加入时间、领取幂等、不可变任务快照；浏览器验证新版本不覆盖已领取记录、复制后目标组修改不影响源组。版本历史显示变更说明与各版题目、标准。 |
| 调整与并发 | 后端验证延期、换题、跳过审批及原因、重复提交冲突；两个线程同时保存同一草稿版本，仅一个成功，另一个返回 409。组长与成员按一致顺序锁定成员、任务、检查记录。 |
| 草稿与正式提交 | 浏览器验证自动保存总结和证据说明、切组恢复、正式提交及重复提交禁用；后端保留正式提交快照，OJ 证据单独存储。 |
| 检查与历史有效性 | 后端验证失败、申诉、复测及完成；换题/重新提交/批准跳过使待检查失效；旧题目或旧提交不能再次检查、申诉或改变新任务状态。历次记录与调整事件保留。 |
| OJ 与 AI | OJ 测试用本地模拟官方响应，验证题目、账号、当日 AC 匹配与外部失败不覆盖原证据；未冒充真实外网验收。AI 测试覆盖去重、异议、模型失败重试、服务重启恢复；浏览器在处理中离开学习页，回来读取结果。完成、OJ、检查与掌握分别表述。 |
| 私人复习与公开分享 | 后端验证默认私有、本人历史、主动分享/撤回；再次失败生成新原因时自动撤回分享，避免自动公开新反馈。资料页仅显示主动分享的原因。浏览器验证复习记录与到期入口。 |
| 周复盘与统计 | 后端分别验证按时完成、延期完成、本周到期未完成；统计按上海日期，保留卡点/调整原因。浏览器保存复盘与下一阶段确认。 |
| 求助与回填 | 后端验证只公开主动填写的提问，公开讨论复制事件不包含私人总结；理解回填限定本人。浏览器验证求助关联任务和回填。 |
| 导航与布局 | 浏览器断言五个群组入口、当前群组与阶段、概览继续学习/待补充/复习跳转；桌面及 390 像素移动截图已人工查看，移动端无横向溢出。源码与截图确认总览顺序、任务主栏/辅助栏及默认收起的 Agent。 |
| 首页只读与复制 | `StudyOverviewController` 只读查询各组，不合并状态；复制同时经过源成员和目标组长检查。浏览器验证汇总只读标识与副本独立。 |
| 数据与部署 | H2 测试实际创建新增表；本机 MySQL 身份 V9、群组 V4/V5 已迁移，真实 MySQL 新建两组完成整套浏览器流程。备份/导入/指纹覆盖新增表。群组 MySQL 池最多 3 个连接、空闲最小值 0，修复历史测试群组累积导致的连接耗尽。 |

模型与 OJ 的外部网络可用性不由本项目保证；真实模型配置由用户在个人设置填写。当前后台检查采用有界工作线程和持久化结果，进程重启后显示暂不可用并允许重试，不提供重启后自动续跑承诺。
