# 第三方组件来源

- Temurin OpenJDK 21 JRE: https://adoptium.net/ ; https://github.com/adoptium/temurin21-binaries
- MySQL Community Server 8.0: https://dev.mysql.com/downloads/mysql/ ; https://github.com/mysql/mysql-server
- PowerShell: https://github.com/PowerShell/PowerShell
- Node.js: https://nodejs.org/ ; https://github.com/nodejs/node/blob/main/LICENSE
- cloudflared: https://github.com/cloudflare/cloudflared ; https://github.com/cloudflare/cloudflared/blob/master/LICENSE

对应许可证在构建时保留或从官方项目下载至发布包 app/tools/licenses 目录。服务端与前端依赖版本见项目 pom.xml 和 frontend/package-lock.json。
